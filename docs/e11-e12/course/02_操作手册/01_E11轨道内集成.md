# E11 轨道内集成

## A 组：BuildChecker 接入 EChecker

在仓库根目录整块执行：

```bash
python3 run_e11e12.py run --request data/integration-sample/e11-a.json --out work/e11-a-01
echo "E11_A_EXIT_CODE=$?"
cat work/e11-a-01/result.json
cat work/e11-a-01/incremental-report.json
```

预期：整体 SUCCEEDED，退出码 0。

1. baseline-full 保存基线的真实 strace、Make 数据库和实际图。
2. baseline-cache.json 的 actual 来自上述图，对齐 main.o/helper.o。
3. incremental-report.json 属于 target_commit，新增 MD extra.h。
4. target-full 的发现集合与增量报告一致。

打开 full-check.json 和 incremental-check.json，核对 schema_version、commit、job_id、trace_id、artifact URI 和 SHA256。进程号不同不影响发现集合比较。

## B 组：DRAFT 接入 MDFixer

```bash
python3 run_e11e12.py run --request data/integration-sample/e11-b.json --out work/e11-b-01
echo "E11_B_EXIT_CODE=$?"
cat work/e11-b-01/draft-build/result.json
cat work/e11-b-01/candidate.patch

```

预期：初始构建 MISSING_MAKE，候选构建成功，最终镜像运行输出 1；固定 MD 报告的 commit 与目标一致；补丁验证 accepted=true，动态重检没有 MD。RD 仍可保留，MDFixer 只修复 MD。

E11 的 fixed-md.json 是固定输入；E12 改为消费真实增量报告。
