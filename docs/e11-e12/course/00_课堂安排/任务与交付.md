# 课堂任务

课程里程碑 E11：A 为 BuildChecker→EChecker；B 为 DRAFT→MDFixer，继续消费固定 MD 报告。

E12：DRAFT→BuildChecker→EChecker→MDFixer→重新构建/检测，使用实际输出衔接各环节。报告中的 commit 必须与修复目标一致。

## 接续 E8–E10

- 复用 lab.py 的 scan、patch、validate；复用原 BuildChecker 的 full_check。
- 增加 DRAFT 候选回放构建适配器，统一项目输出为 1。
- E11-A 将真实 strace 全量图读入历史缓存，之后对目标提交调用增量检测，并与全量结果比较。
- E11-B 构建真实镜像后消费固定 MD，生成补丁并验证。
- E12 由 EChecker 实际报告提供 MDFixer 输入，不再使用固定 MD 文件。
- 新增异步任务 API、幂等键、job_id/trace_id 和带哈希的产物引用。

集成示例采用一个编排服务和四个组件适配器。A/B 通过 SSH 转发访问同一个任务 API。
