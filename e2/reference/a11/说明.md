## ① 接口契约层 —— 「A 组要什么、怎么给」

| 文件 | 说明 | 谁看 |
| --- | --- | --- |
| **`README.md`** | **总索引**。组号与配对组、仓库地址、**服务交接图（含 RD 数据流向）**、文件索引、校验入口、接口一览、产物访问约定、设计原则。 | 助教、B11、组员 |
| **`task.schema.json`** | **规则源头**。一份 Job 表达四类任务：`JobType`（4 个）、`Status`（6 个）、`Finding`（含 `origin` / `suggested_fix`）、**`Delta`（含 `declared` 标志）**、`Artifact`、`SystemError`（6 个错误码），以及四类任务的输入定义。**改字段先改这里，再改样例与校验器。** | 实现者、B11 |
| **`contract-examples.json`** | **样例合集**（合并为一份，便于配对组一次性读取）。四类请求 + 202 受理响应 + 四类查询响应 + 3 条系统错误 + MD/RD 发现 + 产物元数据 + **6 类非法输入**。 | B11、助教 |
| **`openapi.yaml`** | **可选**文件。四个创建端点 + 查询端点 + 产物下载端点的形式化描述，通过 `$ref` 引用 schema。 | 想快速看接口全貌的人 |

| 文件 | 要填什么 | 什么时候 |
