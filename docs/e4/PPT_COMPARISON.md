# E4 两版 PPT 对比

检查日期：2026-10-16。旧文件为 `E4_可重复工程环境_20260929_鼓楼.pptx`，新增文件为 `E4_可重复工程环境.pptx`。仅凭文件名和收到的先后无法证明哪一版是教师最终修订版。

两版均为 23 页；嵌入媒体各 6 个，内容摘要完全相同，没有新增图片。已比较全部幻灯片文字和备注。下表按实际页序引用，旧版页脚有跳号。

| 页 | 原鼓楼版 | 新增版 | B11 处理 |
| --- | --- | --- | --- |
| 4 | work 存个人证据，E4 不要求提交 | 挑选证据后提交 | work 继续忽略；审查后将选定日志放入 e4/evidence |
| 5 | 正文强调本地身份、E4 不要求个人 Git 提交 | 正文强调提交作者用学号、个人贡献占评分 10% | 胡博确认本次 E4 新提交作者为 241276007；不改历史作者。原版备注已有 10% 与学号统计说明，新增版将其写入正文 |
| 6、19 | 运行记录关联模板 SHA | 交付证据对应仓库提交 | 每次运行自动保存完整源码 SHA 和工作区状态 |
| 7 | 具体镜像站和核验见手册 | 增加查询 digest 命令，强调 E2 对外交付的镜像 digest | 保留固定 digest；本地 image ID 与已发布 registry digest 分开记录，不虚构发布 |
| 12 | 默认 app 用户 smoke 验证 Docker Server | make shell 后 docker version | 仍由默认非 root app 做实际 smoke，另验证容器内 Server；shell 可交互检查 |
| 17 | E5 重跑采集完整原始日志；E4 只保留关键行 | E4 失败日志作为 E5 起点；备注要求完整失败日志和退出码 | smoke.json 增加完整 build_log，并导出 smoke-build.log；不把 E4 算作 E5 业务完成 |
| 18 | 组长先初始化，组员再克隆 | 任务顺序表述调整 | 实际依赖仍是先准备仓库，再克隆、doctor、build |
| 20 | 检查两位组员各有成功记录 | 检查提交作者是否学号 | 两项均保留；不能代替组员独立执行 |
| 21、23 | 阿里云初始化、同 digest 镜像站实测说明 | 通用初始化、镜像加速建议 | 按 Other-Instructions.txt 使用华为云，保留可核验的镜像来源 |

第 1–3、8、10–11、13–16、22 页核心内容相同；第 9 页只删去镜像地址见手册的提示。没有增加新业务模块、API 或要求实现完整 DRAFT/MDFixer 算法。

两版都未在幻灯片中给出 2 GB 或 3.5 GiB 服务器最低内存；3.5 GiB 来自随包手册及 doctor.py。胡博于 2026-10-16 转述助教参考配置为 2 GB。B11 为此提供显式资源配置并如实记录差异，实际能否运行以本组证据为准。

补充说明要求组长汇总每人工作与贡献、统一提交。新增 PPT 与命令手册在个人提交措辞上不完全一致：准备每人的运行证据和贡献记录，不要求为凑数量制造代码提交。成员如提交实际变更或自己的证据，使用自己的学号身份。
